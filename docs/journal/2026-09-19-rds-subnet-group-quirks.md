# 2026-09-19: DBサブネットグループ作成でハマった小ネタ2つ

## つまずいた箇所1: 「Create database」ウィザード経由だと3AZ要求された
RDSの「Create database」ウィザードの途中でサブネットグループを作ろうとしたところ、
```
マルチ AZ DB クラスターの場合、3 つの異なるアベイラビリティーゾーンで 3 つのサブネットを選択する必要があります。
```
というエラーになった。

### 原因
ウィザードのデプロイ方式が「Multi-AZ DBクラスター」(2つの読み取り可能なスタンバイを持つ、3AZ構成の高可用性オプション)になっていたため。今回は学習用のシングルAZ構成なので不要な要件だった。

### 解決
RDS左メニューの「Subnet groups」から**単体で**サブネットグループを作成することで回避。デプロイ方式に依存せず、通常通り2AZ(`todo-api-private-1a`, `todo-api-private-1c`)で作成できた。

## つまずいた箇所2: Description欄に日本語を入れたら弾かれた
```
The parameter DBSubnetGroupDescription must not contain non-printable control characters.
```
というエラーになった。日本語(マルチバイト文字)を入力していたのが原因と思われる。

### 学び
RDSなどAWSの古めのAPIでは、名前・説明文系のパラメータが**印字可能なASCII文字のみ**を受け付ける仕様になっていることがある。日本語などのマルチバイト文字を弾く際に、エラーメッセージが「制御文字を含んではいけない」という分かりにくい表現になるのはAWSのクセ。半角英数字で入力し直すことで解決。
