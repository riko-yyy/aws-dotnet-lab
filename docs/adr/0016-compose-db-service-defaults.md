# ADR-0016: DBサービスの起動設定はイメージのデフォルトのまま

## 論点
`db`サービスに`restart`や`user`を明示的に設定するか。

## 選択肢
- 設定する(Docker公式の[.NETガイド](https://docs.docker.com/guides/dotnet/)の例: `restart: always`, `user: postgres`)
- 設定しない(現状)

## 決定
どちらも設定しない。

## 理由
- `restart`: `docker compose up`を手動で実行する前提のローカル環境であり、自動復旧の仕組みは不要。意図せずコンテナが起動し続けるより、明示的に起動・停止したい
- `user`: postgres公式イメージの起動スクリプトは、権限まわりの初期設定を行ってから`postgres`ユーザーに切り替える、という手順になっている。これを外側から`user:`で固定すると、その初期化手順を壊してしまう可能性があるため、イメージのデフォルト挙動に任せる

ヘルスチェック(`pg_isready -U postgres`)側で確認に使うユーザーを明示しているので、動作確認上の実害はない。
