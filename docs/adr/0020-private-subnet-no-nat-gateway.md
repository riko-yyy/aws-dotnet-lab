# ADR-0020: privateサブネットにNATゲートウェイを置かない

## 論点
privateサブネットにNATゲートウェイを設置するか。

## 選択肢
- NATゲートウェイを設置する
- 設置しない(現状)

## 決定
設置しない。

## 理由
privateサブネットにはRDSのみを配置しており、RDS自身が外向き通信(インターネットへのアクセス)を必要としない。ECSはpublicサブネットに`assign_public_ip = true`で配置しているため、ECR pullやCloudWatch Logsへの送信などの外向き通信は、インターネットゲートウェイ経由で完結する。

## 却下した選択肢
- NATゲートウェイの設置: 時間課金が発生するため、現時点で必要性がない。

## 見直しの条件
ECSをprivateサブネットに配置する構成に変更する場合、NATゲートウェイ(またはVPCエンドポイント)が必要になる。
