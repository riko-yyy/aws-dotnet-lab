# ADR-0002: .NETバージョンとAPIスタイル

## 論点
APIを実装する.NETのバージョンと、Minimal API / Controllerベースのどちらを採用するか。

## 選択肢
### バージョン
- .NET 8(前回のLTS)
- .NET 9(STS、サポート終了間近)
- .NET 10(2025年11月リリースの最新LTS)

### APIスタイル
- Minimal API
- Controllerベース(ASP.NET Core MVC形式)

## 決定
.NET 10(LTS)、Minimal APIを採用する。

## 理由
- バージョン: 学習開始時点(2026年9月)での最新LTSであり、今後長くサポートされる。.NET 9はSTSでサポート終了が近く、新規学習用途で選ぶ理由がない
- APIスタイル: 本リポジトリの主眼はインフラの意思決定であり、API設計パターンの学習ではない。Controllerベースに比べてコード量が少なく、TODO程度の薄いドメインでは見通しがよいMinimal APIを選んだ

## 却下した選択肢
- .NET 8 / .NET 9: 新規に学習を始める時点で最新LTSを避ける理由がないため却下
- Controllerベース: 今回の題材(TODO管理、薄いドメイン)に対しては構成の割に記述量が増えるため却下。ただし実務でよく見る構成という点は認識している
