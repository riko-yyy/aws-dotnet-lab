# ADR-0015: DBのポート公開範囲を`127.0.0.1`に限定

## 論点
ローカルDBのポート(5432)を、ホスト側にどこまで公開するか。

## 選択肢
1. `"5432:5432"`(変更前。全ネットワークインターフェースに公開)
2. `"127.0.0.1:5432:5432"`(localhostのみに公開)
3. 公開しない(Docker公式の[.NETガイド](https://docs.docker.com/guides/dotnet/)の`expose`相当。ホストからは繋げない)

## 決定
2(`127.0.0.1`限定)に変更する。

## 理由
ホスト側(Mac)から`psql`やDBクライアントツールで直接繋いで中身を確認したい場面があるため、完全非公開(選択肢3)にはしたくない。一方で、ダミーパスワードとはいえ同じネットワーク上の他の端末から見える状態(選択肢1)を放置する理由もないため、`127.0.0.1`(このMac自身から以外は繋げない)に絞った。

`api`→`db`間の通信はComposeが作る内部ネットワーク(`db:5432`)経由で行われるため、この制限の影響を受けない。

## 却下した選択肢
- 公開しない(選択肢3): ローカルでの動作確認・デバッグのしやすさを優先したため採用しなかった
