# ADR-0022: ECSサービスの`desired_count`は基本0、確認時のみ1にする

## 論点
ECSサービスの`desired_count`をいくつにしておくか。

## 選択肢
- 常に1にしておく(いつでもアクセス可能)
- 基本0にしておき、確認時のみ一時的に1にする(現状)

## 決定
基本0。動作確認する際に一時的に1へ変更して`terraform apply`し、確認後は0に戻す。

## 理由
Fargateは起動中のタスクに対して課金されるため、使わない時間帯は0にしてコストを抑える。

## 却下した選択肢
- 常に1にしておく案: 常時課金が発生するため、学習用ラボの用途では見送り。

## 補足
確認後に0へ戻し忘れないよう、都度チェックする。GitHub Actionsによる自動デプロイ(第5段階)に進んだら、デプロイ時に1へ・検証後に0へ戻す仕組みを検討する。
