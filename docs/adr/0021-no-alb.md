# ADR-0021: ECSの前段にALBを置かない

## 論点
ECSサービスの前段にApplication Load Balancer(ALB)を置くか。

## 選択肢
- ALBを置く
- 置かない(現状、ECSに`assign_public_ip = true`で直接アクセス)

## 決定
置かない。

## 理由
検証段階ではタスク数1での動作確認が中心で、ALBによる負荷分散の恩恵が薄い。ALB自体の時間課金や、ターゲットグループ・リスナー・専用セキュリティグループなど構成要素が増えることも避けたい。

## 却下した選択肢
- ALB + ターゲットグループ構成: 上記の理由により見送り。

## 見直しの条件
複数タスクへのスケールアウト、HTTPS化、独自ドメインでのアクセスのいずれかが必要になったら導入を検討する。
