# ADR-0017: `.dockerignore`は`bin/`/`obj/`のみ

## 論点
`src/Todo.Api/.dockerignore`に何を除外指定として書くか。

## 選択肢
- `bin/`と`obj/`のみ(現状)
- Docker公式の[.NETガイド](https://docs.docker.com/guides/dotnet/)のように幅広く除外する

## 決定
`bin/`と`obj/`のみのまま。

## 理由
ビルドコンテキストを`src/Todo.Api/`に絞っている(ADR-0012)ため、`.git`やリポジトリ直下の`docker-compose.yml`といったファイルは、そもそもビルドコンテキストに含まれない。公式ガイドが幅広い除外パターンを書いているのは、リポジトリ直下をビルドコンテキストにしているケースを想定しているためで、うちの構成には当てはまらない。

## 見直しの条件
将来ビルドコンテキストをリポジトリ直下に広げる場合(ADR-0012の見直し時)や、`src/Todo.Api`配下にサブディレクトリ・別プロジェクトを追加する場合は、`bin/`/`obj/`を`**/bin`/`**/obj`に書き換える必要がある(現状の`bin/`はビルドコンテキストのルート直下だけを指すため)。
