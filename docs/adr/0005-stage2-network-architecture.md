# ADR-0005: 第2段階のネットワーク構成

## 論点
ECS Fargateで動かすTODO APIを外部からアクセス可能にする際、どのネットワーク構成にするか。

## 選択肢
- A案: パブリックサブネットに配置し、Fargateタスクに直接パブリックIPを付与(ALB無し)
- B案: パブリックサブネット + ALB(Application Load Balancer)
- C案: プライベートサブネット + NAT Gateway + ALB

## 決定
A案。パブリックサブネットに配置し、Fargateタスクへ直接パブリックIPを付与する。

## 理由
- 個人の学習用途であり、可用性や複数台構成、SSL終端などALBが提供する機能が今の時点で必要ない
- ALB(月$16〜20)、NAT Gateway(月$30〜45)はいずれも固定費であり、個人ラボの学習コストとしては過大
- 第2段階の目的は「ECS Fargateでコンテナを動かす」ことの理解であり、ネットワーク構成の作り込みは主目的ではない。まずは最小構成で動かし、必要になった時点でALBありの構成を追加で試す方針とする

## 却下した選択肢
- B案(ALBあり): 実務に近い構成だが、固定費が発生する割に今の学習段階では得られるものが少ないため一旦保留。将来的に複数タスクへの負荷分散やHTTPS対応を試したくなったタイミングで別途検討する
- C案(プライベートサブネット+NAT Gateway+ALB): 最も「本番相当」だが、コストが最も高く、個人ラボの検証用途には過剰
